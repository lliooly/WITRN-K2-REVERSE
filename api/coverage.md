## 契约范围

- 15 个 JSON 操作均有请求字段、主要结果、模式、文件 / 设备副作用与控制约束。
- Python 文档覆盖 112 个显式非私有函数 / 方法 / 属性 / 构造器，参数默认值对应源码；内部组合函数注明用途，不承诺所有条目为稳定 SDK。
- 13 类设备命令 / 响应 / 主动报告列明读、写、控制、负载和 ACK 行为；部分研究长度不进入正式 SDK 保证。
- 三个可执行离线示例验证调用路径；真实 USB 只读示例供持有设备的开发者自行复核。

## 待补充的接口与验证

1269 条恢复方法与 574 组代理只提供定位元数据；未知内部函数没有逐项语义，不能视为 1269 个已文档化接口。保护器 VM 全语义、K2Picture 一键恢复、原生 Qt 完整自动分析、私有加密认证、设备运行时模式切换、CC1 / CC2、远程采样率设置和设备离线存储下载未完整确认。

K2Picture 原报告 token / RID 的定位疑点明确保留，未用于新设备 API 推导。已识别格式仍可依据其独立结构路径研究。

## 维护原则

我会同步维护 `api/` 中的参数、返回、副作用说明和示例，并为设备能力标注静态分析、合成测试或实机验证依据。集成时以接口契约和固定提交为基线；未确认的方法语义与设备能力保留为待验证项。
