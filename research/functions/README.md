## 机器可读索引

- [upv30-methods.json](upv30-methods.json)：1269 条原始 / 恢复方法定位，不含 IL 或 C# 体。
- [upv30-proxies.json](upv30-proxies.json)：574 组字段 / 目标关联，不含函数体。

查找 RID 439：

```sh
python3 - <<'PY'
import json
data = json.load(open('research/functions/upv30-methods.json'))
print(next(row for row in data['methods'] if row['rid'] == 439))
PY
```

代理目标可为 MethodDef 或 MemberRef；应先判断 token 高字节，不要把低位都当 MethodDef RID。完整索引是历史产物的元数据连接，不等于此次重跑全部方法恢复。
