# 材料来源与公开范围

## 公开内容

本库从原应用仓库的已提交版本提取 `reverse/` 全部顶层报告和脚本、`k2up/` 全部 Python 模块及必要协议表、`tests/` 全部合成测试，以及 `docs/` 的协议、实测、设计和 UI 背景文档。来源提交见 [快照信息](../evidence/snapshot.json)。原库本地尚未提交的修改未混入该快照。

此外保留方法恢复验证、固件检查和固件校验的历史 JSON 摘要。这些摘要不包含原始代码体、设备序列号或 USB 路径；它们是历史证据，不是本次重新完成的硬件验证。

[文件目录](../CATALOG.md) 逐项列出公开文件用途，[发布清单](../MANIFEST.json) 提供大小与 SHA-256。

## 本地保留的材料

| 类别 | 本地位置 / 示例 | 公开替代材料与复现方式 |
| --- | --- | --- |
| 厂商 Windows 程序及依赖 | 根目录 DLL / EXE / PDB、`K2Picture_1.1/`、`WITRN_PC_V1.0.4/` | 输入哈希、产品标识和研究报告；使用者自行取得合法输入 |
| 官方固件和压缩包 | `K2_V5.8/`、`.k2`、`.zip` | 格式说明、校验摘要、输入哈希和解析脚本 |
| 托管资源 / 方法体 / 恢复程序集 | `reverse/dotnet/` | 静态恢复脚本、历史验证摘要；本地运行生成 |
| 完整反编译与局部摘录 | `reverse/decompiled/`、`reverse/native-decompiled/`、`reverse/focused/` | 报告中的方法 RID、调用映射、地址和格式解释 |
| IDA 工程与工作数据库 | `.i64`、`.id0`、`.id1` 等 | 输入哈希及已整理的分析定位信息 |
| 导出的完整表 | `reverse/tables/` | 提取脚本；只保留解析必需的 256 字节替换表，并在 NOTICE 中单独声明其来源 |
| 解码应用镜像 | `reverse/firmware/*.bin` | 非代码体的 JSON 摘要、校验与向量信息 |
| 实机数据、备份和原始日志 | `reverse/validation/`、`k2_logs/`、`k2_backups/`、`k2_recordings/`、`build/` | 经人工整理的实测汇总与验证范围 |
| 私人图片及设备工程 | `.k2project`、`.k2image`、`.k2emark` 等 | 合成测试覆盖格式，不公开用户原始作品 |

以上本地目录属于原研究工作区；本仓库不附带这些文件。公开边界用于保留第三方权利和用户隐私，不意味着已经完成全部分析或取得所有第三方授权。

## 第三方来源

唯一直接改编代码来源为 MIT 的 `didim99/witrn-driver`，详见 [third_party](../third_party/README.md)。研究中参考的其他项目保留在调查文档的来源表中，没有因此复制其完整源码。

原应用使用的 GPL-3.0 DFU 插图未包含在本库；本库不包含应用图片资源，因而不复制该图片或其图像许可证文件。产品名称不表示官方授权。
