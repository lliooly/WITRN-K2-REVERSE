## 资料核验发现的定位疑点

K2Picture 原报告同时记录解码入口 RID 724 和 VM 程序 1 token `0x06000724`。token 低位 `0x724` 对应十进制 RID 1828，不等于 724。现有资料不足以确认两者关系，暂不标为同一个方法；原报告保留，函数索引明确标注，需在对应元数据 / VM 输出中复核。
